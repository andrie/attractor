# Plot a strange attractor.

Plot a strange attractor.

## Usage

``` r
# S3 method for class 'attractor'
plot(
  x,
  palette = "BuPu",
  invert = FALSE,
  dims = c(600, 600),
  zero_colour = NA,
  trim_quantiles = 0,
  trans = "log1p",
  ...
)
```

## Arguments

- x:

  Attractor, generated by
  [`attractor_sprott_7e()`](https://andrie.github.io/attractor/reference/attractor_sprott_7e.md)

- palette:

  ColorBrewer palette. This value is passed to
  [`scales::col_numeric()`](https://scales.r-lib.org/reference/col_numeric.html)

- invert:

  If `TRUE`, inverts the colour scale

- dims:

  Dimensions of matrix

- zero_colour:

  Colour to use for zero and NA values

- trim_quantiles:

  Numeric value, indicating a trim value. Quantiles below this value, as
  well as higher than `(1 - trim_quantiles)` will be removed from data
  prior to plotting.

- trans:

  Transforming function

- ...:

  Other options passed to
  [`plot()`](https://rdrr.io/r/graphics/plot.default.html)

## Value

Raster, invisibly

## Examples

``` r
# Generate the seed vector (14 random values)
a <- seed_sprott_7e(fast_forward = 429)

# Generate points, trim at the 0.03 quantile, and discretize to a 600x900 matrix
dat <- attractor_sprott_7e(a, n = 1e6, qs = 0.03, dims = c(600, 900))

# Plot using various palettes from `RColorBrewer`
plot(dat, palette = "Oranges")

plot(dat, palette = "Greens")


plot(dat, palette = "Oranges", zero_colour = "#FFFAF6")

plot(dat, palette = "Oranges", zero_colour = "grey20", invert = TRUE)
```
