# Generate attractor for the Sprott 7e attractor.

Generate attractor for the Sprott 7e attractor.

## Usage

``` r
seed_sprott_7e(fast_forward, seed = if (!missing(fast_forward)) 1 else NA)
```

## Arguments

- fast_forward:

  "Index value" to retrieve

- seed:

  Original seed value, passed to
  [`set.seed()`](https://rdrr.io/r/base/Random.html)
