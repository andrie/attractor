# Package index

## Sprott 7E attractor

Generate the data points using the attractor defined by Sprott, in
equation 7E of his book.

- [`seed_sprott_7e()`](https://andrie.github.io/attractor/reference/seed_sprott_7e.md)
  : Generate attractor for the Sprott 7e attractor.
- [`attractor_sprott_7e()`](https://andrie.github.io/attractor/reference/attractor_sprott_7e.md)
  : Generate strange attractor using equation 7E of Sprott.
- [`png_sprott_7e()`](https://andrie.github.io/attractor/reference/png_sprott_7e.md)
  : Draw a Sprott 7e attractor straight to a PNG file.

## Recolour and plot

Change the colour of the plot and background

- [`plot(`*`<attractor>`*`)`](https://andrie.github.io/attractor/reference/plot.attractor.md)
  : Plot a strange attractor.
- [`recolour()`](https://andrie.github.io/attractor/reference/recolour.md)
  [`recolor()`](https://andrie.github.io/attractor/reference/recolour.md)
  : Use palette from ColorBrewer to recolour the image.
